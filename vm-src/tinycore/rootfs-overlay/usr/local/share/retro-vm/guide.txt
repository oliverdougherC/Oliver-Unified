OD Retro VM
===========

This Tiny Core remaster is tuned for:

- fast boot
- a retro desktop shell
- stable local input
- outbound network access through the page relay
- automatic DHCP on eth0 at boot
- curl and neofetch available at boot

Launchers:

- Guide: this window
- Browser: Firefox when installed, otherwise install notes

Tips:

- Click the VM to capture the pointer
- Press Escape to release it
- Fullscreen stays edge-to-edge
- Run retro-vm-network to retry DHCP on eth0
- Run retro-vm-install-firefox to install latest Firefox
- Try curl https://example.com after networking is up
- Run neofetch for system info
- Tiny Core uses tce-load / tce-ab, not apt
