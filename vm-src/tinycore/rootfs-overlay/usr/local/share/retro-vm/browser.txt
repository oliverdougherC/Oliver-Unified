Retro Browser
=============

Networking is configured automatically at boot. If you need to
retry DHCP manually, run:

  retro-vm-network

Tiny Core does not use apt. Its built-in package system is tce:

  tce-load -wi <extension-name>
  tce-ab

To install the latest Firefox available through Tiny Core's
Firefox installer extension, run:

  retro-vm-install-firefox

After installation, the desktop Browser launcher will open Firefox
if the firefox command is available. The ISO does not bundle Firefox
itself, so boot stays small and quick.
